# Telegram Message Bot 🤖

ربات دریافت پیام و پاسخ مستقیم.

## قابلیت‌ها
- نمایش نام، username و User ID فرستنده برای مدیر
- دریافت متن، عکس، فایل و سایر پیام‌های معمول
- دکمه پاسخ مستقیم به کاربر
- اعلام شفاف به کاربر که ربات ناشناس نیست

## متغیرهای محیطی
BOT_TOKEN=توکن ربات
ADMIN_ID=آیدی عددی مدیر

توکن را داخل GitHub قرار نده.

## اجرا
python bot.py
